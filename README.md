# theweekendpit.com

Static one-page site for The Weekend Pit newsletter. Plain HTML, no framework, no build step — one file plus assets.

- **Hosting:** GitHub Pages, deployed from `main`. Custom domain: theweekendpit.com.
- **Signup:** the form is a beehiiv embed — the subscriber list and sends live in beehiiv, not here.
- **Assets:** `assets/` holds the brand marks, favicons, the Temperature Sheet PDF, and its thumbnail.

## Editing

Edit `index.html`, commit to `main`, and Pages redeploys automatically in about a minute.

Brand short version: oxblood `#6B2B2B`, brass `#B5762E`, charcoal `#1F1C1A`, bone `#F2ECE2`. Never shrink the full stamp below 80px — use the micro mark instead.
